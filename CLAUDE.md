## Продукт

**EscrowNad** — эскроу, который платит по внешнему факту, а не по доверию
сторон. Покупатель кладёт USDC в контракт на Monad; деньги уходят продавцу
только когда официальный интернет-реестр опубликовал переход прав на ресурс.
Первый класс активов — блоки IPv4 через RIPE.

**Полное описание — в [`README.md`](README.md)**: рынок, механика, комиссии,
честные ограничения, адреса контрактов. Он подробный и актуальный — не
пересказывай его здесь и не дублируй, читай его.

Что дальше по плану — [`ROADMAP.md`](ROADMAP.md).

## Стек и раскладка

Приложение на **forge** — внутренней платформе, лежащей рядом в
`../forge/` как path-зависимость. Публично forge не выложен, поэтому
`cargo build` из клона репозитория не проходит: это заявлено в README как
ограничение, а не как баг.

Четыре сервиса плюс обсервер, общаются через unix-сокеты. Порядок старта важен:

```
database → notifier → ws → web        (+ escrownad-observer отдельно)
```

```
src/
├── bin/          # пять бинарей
├── observer/     # оракул: таблицы переходов RIPE + RDAP. Без зависимостей от forge
├── chain/        # вызовы контракта
├── cleanverse/   # CVI: верификация личности сторон
├── models/       # deal, demo
├── pages/        # index, deals, oracle, cabinet, about, admin/demos
├── ws_handlers/  # deals, demos, echo
├── moderation.rs, tg_hook.rs, wallet_auth.rs, sanitize.rs
contracts/        # EscrowLock.sol + интерфейсы, собирается одним Foundry
templates/        # tera
seeds/ sqls/      # SQL отдельными файлами, не в коде
etc/              # локальные конфиги; deploy/etc/ — продовые
```

`src/observer/` и `contracts/` намеренно свободны от forge — по README их можно
проверить независимо. **Не втягивай туда платформенные зависимости.**

## Локальный запуск

Порты: web `:4100`, ws `:4101`. База — `escrownad.com` через туннель на
`127.0.0.1:5432`, см. `etc/database.toml`.

```bash
cargo build --bins
mprocs                 # поднимает database/notifier/ws/web разом
```

Обсервер прогоняется одним проходом:

```bash
OBSERVER_ONCE=1 ./target/debug/escrownad-observer
```

| | |
|---|---|
| Сайт | http://localhost:4100/ |
| Доска | http://localhost:4100/deals/ |
| Оракул | http://localhost:4100/oracle/ |
| Админка | http://localhost:4100/admin/ |
| Вход | `adm@escrownad.com`, пароль в `pass.txt` (не в git) |

## Каноны

**forge — не изобретать своё.** Формы собираются готовыми компонентами:
`<chips>`, `<fixed_n>`, `<wysiwyg>`, `<toggle>`, `<file_upload>`. Клиент
собирает значения через `Form.collectInputs`, дальше — в WS-хендлер. Не пиши
свой виджет там, где у платформы есть штатный.

Канон платформы — в `../forge/docs/`, вход через `_INDEX.md`. Он **не**
подгружается автоматически при работе здесь: открывай сам, когда трогаешь
форджевые механизмы.

**Деньги — через `fixed_n`.** Никакой арифметики на float. Цены в USDC — scale 8,
ввод целыми.

**HTML из wysiwyg — только через `sanitize.rs`.** Описание лота рендерится
через `| safe`; без санитайза это дыра XSS.

**SQL — в `sqls/`, не в строках Rust.**

**Единственный источник правды по комиссии — `quote(amount)` в контракте.**
Не дублируй ставки в интерфейсе и в базе.

## Правила оператора по продукту

- поверхность продукта — **только английский**. Русский остаётся во внутренних
  документах и в общении;
- вход **только кошельком**, пароля на публичной поверхности нет;
- **интерфейс для идиотов**: под каждым контролом простая подсказка. Если
  пользователь не понял — виноваты мы, а не он;
- одна кнопка **Add**, а не пара CTA под offer и request;
- иконки берём из набора Дедала в `static/icons/`, подключение — CSS-маской по
  `currentColor`;
- числа пишутся так, как их пишет человек.

## Границы

**Не твоё:**

- ядро `forge` — это зона Гефеста. Нужна правка в крейтах — задача ему, не
  правь сам;
- миграции и секреты в базе — применяет оператор руками;
- машина, supervisor, nginx, порты — зона Кратоса (`~/CLAUDE.md`). Нужен
  деплой — задача ему.

**Гейт на оператора:** бамп версии forge, деплой в прод, всё, что меняет
контракт на живой сети.

## Что не уходит в публикацию

Репозиторий публичный. В `.gitignore` уже закрыты и должны там остаться:

- `.private/` — внутренние заметки, черновики заявок, разборы;
- `docs/vendor/` — чужая документация, полученная по инвайту;
- `pass.txt`, `*.secret.txt`, `synapse.toml`, `.mcp.json`, `etc/*secret*`;
- `.claude/` — рабочие заметки ассистента и хендофы сессий.

Перед коммитом проверяй, что личных адресов и ключей в диффе нет. Один раз
почту из манифеста уже вычищали отдельным коммитом — второй раз не надо.

## Коммиты

Коммиты в этом репозитории — твоя работа, не оператора. Сообщение описывает
эффект для человека, а не механику правки: не «поправил условие в фильтре», а
«demand listings behaved as if every lot were an offer». Язык сообщений —
английский, как и остальная публичная поверхность.
