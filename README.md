# EscrowNad

Safe escrow that settles on **external proof**. Built on **Monad**.

Not a generic arbiter-escrow. Money unlocks when an oracle confirms a real-world condition (first module: RIPE IP transfers; later: domains/whois, digital assets).

Hackathon target: Cleanverse Build (Trusted Assets) — demo on Monad.
